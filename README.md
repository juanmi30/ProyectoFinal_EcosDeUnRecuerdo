## ⚙️ Pre-requisitos

Para desarrollar o ejecutar la aplicación se requiere:

### **Para desarrollo**
- Unity **2021.3.x LTS**
- SDK XR Interaction Toolkit (instalable desde Unity Package Manager)
- Android Build Support (si exportas a Meta Quest)
- Meta Quest Link o visor Quest para pruebas

### **Para ejecutar en visor Meta Quest**
- Activar *Unknown Sources* desde configuración del visor
- Archivador compatible para instalar el archivo `.apk`

## 🧠 ¿De qué se trata este proyecto?

Este proyecto explora el uso de **Realidad Virtual como herramienta experimental para la resignificación de recuerdos traumáticos**, combinando:

✔️ **Narrativa inmersiva**  
✔️ **Interacción en primera persona**  
✔️ **Ambientes audiovisuales evocativos**  
✔️ **Elementos simbólicos de memoria emocional**  

El usuario recorre dos escenarios:

1. **Escena Interior — Escuela abandonada**  
   - Textos flotantes narrativos que aparecen dinámicamente.  
   - Secuencias que evocan ansiedad, soledad y espera.  
   - Exploración del impacto emocional de un recuerdo de abandono.

2. **Escena Exterior — Bosque y carretera**  
   - Sonido ambiental envolvente.  
   - Elementos simbólicos (carro alejándose, guardias que representan límites).  
   - Final interactivo según exploración del jugador.

Este proyecto es un **primer prototipo** para una investigación más amplia sobre VR terapéutica, narrativa emocional y resignificación de experiencias traumáticas.

## 📦 Cómo descargar el código para desarrollo

### Opción 1 — Clonar con Git

```bash
git clone https://github.com/juanmi30/ProyectoFinal_EcosDeUnRecuerdo.git
````

### Opción 2 — Descargar ZIP

1. Ve al repositorio en GitHub.
2. Clic en **Code → Download ZIP**.
3. Extrae el archivo.
4. Abre la carpeta raíz con **Unity 2021.3 LTS**.

> ⚠️ No abras directamente la carpeta `Assets/`.
> Abre siempre la carpeta donde esté `ProjectSettings/` y `Assets/`.

---

## ▶️ Cómo usar el EJECUTABLE (APK en Meta Quest)

1. Descarga el archivo `.apk` desde la carpeta *Releases*.

2. Conecta tu Meta Quest al PC mediante USB.

3. Instala el APK usando:

   * **SideQuest**, o
   * `adb install nombre.apk`

4. En el visor:

   * Ve a **Apps → Unknown Sources**.
   * Busca el nombre de tu proyecto.
   * Ejecuta la experiencia VR.

> Recomendación: usar audífonos o buen volumen para mayor inmersión.
